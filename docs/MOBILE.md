# Mobile app (Capacitor)

The iOS and Android apps use **Capacitor** to wrap the exact same web build
(`dist/`) in a native shell — the same UI as web and desktop, one codebase to
maintain. Capacitor was chosen over React Native / Flutter precisely because it
reuses this React/TS/Tailwind app verbatim instead of forking the UI (see the
stack rationale in the README).

## What's wired

- **Platform detection** (`src/platform/index.ts`): `isCapacitor()`, `isNative()`,
  `getPlatform()` → `'ios' | 'android' | 'desktop' | 'web'`.
- **Native haptics** (`src/platform/haptics.ts`): a play triggers the Taptic /
  vibration engine via `@capacitor/haptics` on device, falling back to the web
  Vibration API in the browser. Non-blocking and best-effort.
- **Status bar & back button** (`src/platform/native.ts`): status-bar style
  follows the theme; the Android hardware **back button** closes the open modal
  (or stops playback) before exiting.
- **Safe-area insets**: the layout pads for notches / rounded corners via
  `env(safe-area-inset-*)` (0 on web/desktop), and the viewport uses
  `viewport-fit=cover`.
- **Offline**: the app is already offline-first (IndexedDB + service worker), so
  it works with no network on device out of the box.

All native plugins are **dynamically imported**, so the browser bundle never
loads them on its critical path.

## Prerequisites

- Node 20+, and the web build (`npm run build`)
- **iOS:** macOS + Xcode + CocoaPods
- **Android:** Android Studio + JDK 17 + Android SDK

## First-time setup

The native platform folders (`ios/`, `android/`) are generated by Capacitor and
are **not** committed — create them once per clone:

```bash
npm install
npm run build
npx cap add ios       # creates ios/  (macOS only)
npx cap add android   # creates android/
```

## Develop & run

```bash
npm run mobile:ios       # build web → cap sync ios → open Xcode
npm run mobile:android   # build web → cap sync android → open Android Studio
# then Run from the IDE onto a simulator/emulator or device
```

After any web change, re-sync the native shell:

```bash
npm run build && npx cap sync
```

## Required native permissions

The recorder uses the microphone, so declare it before submitting:

- **iOS** — add to `ios/App/App/Info.plist`:
  ```xml
  <key>NSMicrophoneUsageDescription</key>
  <string>Record custom sounds for your soundboard.</string>
  ```
- **Android** — add to `android/app/src/main/AndroidManifest.xml`:
  ```xml
  <uses-permission android:name="android.permission.RECORD_AUDIO" />
  ```

- Swap IndexedDB for the native **SQLite** plugin on device for very large libraries.
- Share-sheet / Files import, background audio, and landscape polish.
- Per-page swiping (ships with the multi-page milestone).

> **Verification note:** the web integration is built and browser-verified
> (native detection correctly reports web; haptics/status-bar calls no-op safely
> off-device). Compiling the actual `.ipa`/`.aab` requires Xcode / Android Studio
> and is done on a developer machine or mobile CI — it can't run in this
> headless environment.
